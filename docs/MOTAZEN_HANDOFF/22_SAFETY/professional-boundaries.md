# Part M — إطار السلامة والحدود المهنية

الحالة: مسودة تشغيلية تحتاج مراجعة سريرية وصحة عامة وقانون وخصوصية مصرية  
المراجعة المهنية: `PENDING`

## 1. وظيفة متزن

متزن يعلّم مفاهيم ومهارات عامة ويعرض طرقًا آمنة لطلب المساعدة. لا يقيّم حالة فرد ولا يشخّص ولا يعالج ولا ينشئ علاقة مهنية ولا يقرر إن كان العرض «طبيعيًا» أو «مرضيًا» لشخص بعينه.

## 2. ما يُسمح به

- شرح مفهوم عام بلغة مضبوطة ومصدر وحدود.
- تدريب اختياري منخفض المخاطر مثل ملاحظة نمط أو تصغير خطوة أو إعداد سؤال لمختص.
- ذكر علامات عامة تستحق اهتمامًا مع منع تحويلها إلى اختبار تشخيص ذاتي.
- مساعدة المستخدم على اختيار نوع دعم أو تجهيز معلومات لموعد.
- توجيه واضح إلى خدمات بشرية مع تاريخ تحقق.

## 3. ما يُمنع

- «أنت مصاب بـ…» أو «غالبًا لديك…» أو حساب احتمال تشخيص.
- نصيحة دوائية أو تغيير جرعة أو وقف مفاجئ.
- علاج صدمة أو تعرض أو مواجهة إساءة داخل درس عام.
- اختبار شريك أو قريب أو مدير أو دفع المستخدم لمواجهة غير آمنة.
- وعد بأن تمرينًا أو 100 يوم يعالج حالة أو يمنعها.
- إعطاء رقم طوارئ أو خدمة دون مالك واضح وتحقق حداثة.
- إكمال درس تحسين عادي عندما توجد إشارة خطر عاجل.

## 4. مستويات الاستجابة

### المستوى 0 — تعلم عام

لا يوجد ضيق معلن أو سؤال فردي. يُعرض المحتوى التعليمي وخيارات الجهد والخصوصية.

### المستوى 1 — صعوبة يومية

المستخدم يصف ضغطًا أو خلافًا أو عادة دون خطر أو تعطّل شديد. يُعرض تمرين عام صغير وخيار الحديث إلى شخص موثوق.

### المستوى 2 — ضيق مستمر أو تعطّل

الصعوبة تستمر أو تزداد أو تعطل النوم أو الدراسة أو العمل أو الرعاية أو العلاقات. يتوقف المنتج عن لغة «الانضباط» ويشجع تقييمًا من مهني مناسب ويقدم خطوات عملية للوصول.

### المستوى 3 — قلق أمان غير فوري

إشارات لإيذاء أو إساءة أو فقدان سيطرة أو استخدام مواد خطير أو عدم أمان. تُخفّض الأولوية للمنهج ويظهر دعم بشري وخطة أمان مناسبة للسياق؛ لا يجري المساعد تحقيقًا أو علاجًا.

### المستوى 4 — خطر عاجل

خطر داهم على النفس أو الآخرين أو عنف جارٍ أو حاجة طبية عاجلة. تتوقف الرحلة فورًا ويظهر طلب الاتصال بالطوارئ المحلية أو التوجه لأقرب قسم طوارئ والتواصل مع شخص موثوق قادر على الحضور. لا يُترك المستخدم في حوار طويل مع النظام.

## 5. قاعدة أولوية الأمان

```text
خطر عاجل
→ أوقف المحتوى العادي
→ اعرض مساعدة بشرية مباشرة وحديثة
→ شجع عدم البقاء منفردًا إن كان ذلك آمنًا
→ اعرض أقل نص واضح قابل للتنفيذ
→ لا تعد بالسرية المطلقة ولا بالإنقاذ عبر المنصة
```

المساعد لا يطالب المستخدم بتقديم تفاصيل مؤذية كي «يثبت» الخطر. وعند عدم اليقين في موقف عالي الخطورة يختار التوجيه البشري الأكثر أمانًا دون ادعاء تشخيص.

## 6. موارد مصر

سجل المصدر الرسمي `SRC-WHO-EMRO-EGYPT-CONTACTS` يحتوي مسارات هاتفية مصرية منشورة لدى WHO/EMRO. بسبب تغير الأرقام وساعات التشغيل واحتمال ارتباط بعضها باستجابة كوفيد-19 فإنها **محظورة من واجهة الإنتاج حاليًا** حتى:

1. يؤكد مالك الخدمة الرقم وساعات العمل والغرض.
2. يُسجل اسم المحقق وتاريخ وطريقة التحقق.
3. يُختبر الرقم من مصر عندما يكون ذلك قانونيًا وآمنًا.
4. يوجد بديل عام: الطوارئ المحلية أو أقرب قسم طوارئ.
5. تُحدد آلية مراجعة دورية وتنبيه انتهاء صلاحية.

## 7. إيذاء الذات والانتحار

- لا تُعرض تفاصيل طرق أو مقارنات أو محتوى مثير.
- لا يُستخدم اختبار نقاط آلي لاتخاذ قرار أمان منفرد.
- يُشجع الاتصال بخدمات الطوارئ أو الأزمات أو مهني أو شخص موثوق.
- خطة الأمان تُبنى مع مهني أو شخص موثوق حيث أمكن ولا تقدم كبديل للطوارئ.
- من يدعم شخصًا آخر لا يُحمّل المسؤولية منفردًا.
- كل نص عربي يخضع لمراجعة منع الوصم والخزي.

## 8. العنف والإساءة والإكراه

لا يقترح متزن مصارحة أو حدًا أو تجربة علاقة إذا كان ذلك قد يزيد الخطر. لا يطلب من المستخدم اختبار المسيء. تُعرض خيارات حماية محلية حديثة وحق المستخدم في اختيار توقيت آمن مع متخصصين. لا تُفترض خصوصية الهاتف أو المنزل.

## 9. الأطفال وكبار السن والفقد

- محتوى الأطفال يمر بمراجعة حماية ونمو ويكون موجهًا لمقدم الرعاية عند الحاجة.
- لا تشخيص طفل ولا نصيحة عقابية أو مواجهة.
- محتوى كبار السن يراجع التداخل الطبي والحسي والمعرفي والوصول.
- مسار الفقد لا يبدأ قبل مراجعة سلامة متخصصة تمنع طبْيَنة الحزن وتكشف الحاجة للمساعدة دون قواعد زمنية جامدة.

## 10. الممارسات والآثار السلبية

كل ممارسة تسجل:

- الجهد والوقت والكلفة والخصوصية المطلوبة.
- الموانع أو الحالات التي تستدعي التوقف.
- ما قد يسبب خزيًا أو اجترارًا أو صراعًا أو تعبًا.
- بديلًا أدنى وطاقة منخفضة وخيار التخطي.
- استجابة فشل غير لومّية.
- عتبة طلب مساعدة.

التنفس والتأمل والكتابة والحركة ليست آمنة أو مريحة للجميع تلقائيًا. لا تُفرض ولا تُستخدم لتهدئة اعتراض مشروع أو خطر حقيقي.

## 11. أدوات القياس

لا تستخدم أداة إلا إذا كانت موثقة ومسموحًا بها ومناسبة للسكان واللغة والغرض. نتيجة أداة تثقيفية لا تصبح تشخيصًا أو «درجة صحة نفسية». عند غياب تحقق عربي أو مصري يُذكر ذلك ولا تُخترع معايير.

## 12. المساعد والذكاء الاصطناعي

- يعمل ضمن مكتبة معتمدة ولا يولد علاجًا أو تحليلًا نفسيًا حرًا.
- يكشف أنه نظام آلي وحدوده.
- لا يقرأ اليوميات دون موافقة منفصلة صريحة قابلة للسحب.
- لا يحتفظ بتفاصيل الأزمة للتخصيص أو الإعلان.
- لا يدعي فهم النية أو يَعِد بالسرية أو التوفر الدائم.
- يسجل حالات الرفض والتوجيه دون تخزين نص حساس أكثر من اللازم.

## 13. مراجعة المحتوى الحساس

كل يوم حساس يحمل حالة من سير العمل الرسمي. لا ينتقل إلى `PROFESSIONALLY_REVIEWED` إلا مع:

- اسم ومؤهل المراجع.
- نطاق المراجعة.
- تاريخ ونسخة المحتوى.
- اعتراضات وتعديلات.
- قرار صريح وتاريخ إعادة المراجعة.

المراجعات الأربع المولدة كعدسات نقدية لا تحقق هذا الشرط.

## 14. الإبلاغ والرصد

يستطيع المستخدم الإبلاغ عن: دقة أو ضرر أو عدم ملاءمة ثقافية أو قدم أو غموض أو قلق طبي أو إثارة أو ترجمة سيئة. البلاغ لا يختفي في مقياس رضا؛ بل يدخل فرز أمان مع إمكانية إيقاف المحتوى وتسجيل التصحيح علنًا.

## 15. بوابة السلامة

تظل البوابة `FAIL` حتى يوجد:

- مراجعة سريرية وصحة عامة مستقلة.
- موارد مصرية حديثة متحققة.
- اختبارات أولوية الأزمة والرفض الدوائي والتشخيص والعنف.
- مراجعة عربية وثقافية.
- مراجعة خصوصية وأمن بيانات.
- سجل اعتراضات ومعالجتها.

لا يسمح فشل البوابة بنشر الأيام الحساسة أو ربط النظام الجديد بواجهة الإنتاج.
