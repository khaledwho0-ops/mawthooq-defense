# الحدود المعروفة وحواجز النشر

الحالة: صالحة للإفصاح الداخلي؛ لا تعني أن المنتج جاهز للنشر.

- متزن 2.0 تعليم غير سريري. لا يشخّص أو يعالج أو يقيّم خطرًا فرديًا، ولا يحل محل طبيب أو معالج أو محامٍ أو مستشار مالي أو طوارئ.
- لم تُجرَ تجربة فاعلية للمسار الكامل. مئة يوم و44 حقلًا لكل يوم تثبت اكتمال المسودة، لا الأثر أو السلامة أو الملاءمة.
- الأدلة المصرية المباشرة محدودة وغير متوازنة بين المناطق والطبقات والأعمار والأدوار والإعاقات. كثير من المصادر دولي أو جامعي.
- المراجعة السريرية والصحة العامة والثقافية واللغوية والخصوصية والوصول الخارجية لم تكتمل، ولا يوجد اعتماد مهني منسوب.
- موارد المساعدة المحلية غير معتمدة للنشر. لا يجوز عرض اسم أو رقم أو ساعات قبل تحقق تشغيلي حديث ومالك مسؤول واختبار وصول.
- البنية التقنية لم تُنفذ أو تُختبر. مواصفات الخصوصية وعدم التخزين والحذف والمعالجة لكل استخدام ليست ضمانًا قبل التنفيذ والتدقيق المستقل.
- البحث والأنطولوجيات قد توجّه إلى محتوى فقط، ولا تملك صلاحية تشخيصية. «لا أعرف ما المشكلة» يبقى مسارًا غير تشخيصي.
- ممارسات العلاقات لا تناسب العنف والسيطرة والانتقام. الأمان والدعم يسبقان الحوار، والمسامحة والثقة والاتصال مستقلة.
- ممارسات المال والعمل والمجتمع لا تقدم نصيحة قانونية أو استثمارية أو مهنية، ولا تزيل قيود الدخل والأسعار والسلطة والقانون.
- الخطط والعادات والقياس الذاتي قد تزيد الضغط أو المراقبة. الراحة والتخطي والتوقف والحذف وطلب المساعدة نتائج كاملة.
- الذكاء الاصطناعي اختياري ولا يستقبل بيانات حساسة افتراضيًا. لا توجد سرية مطلقة أو ضمان حذف خارج حدود السيطرة التقنية.
- المسارات الأخرى في كون الأدوار مخططة وليست 100 يوم مكتوبة. الأولوية المنجزة نصيًا هي «إنسان متزن» فقط.

## حواجز لا يجوز تجاوزها

1. قرارات مراجعة بشرية منسوبة للأمان السريري والصحة العامة والثقافة واللغة والوصول والخصوصية.
2. اختبار مستخدمين مصريين مع موافقة وانسحاب ورصد ضرر وخطة إحالة.
3. تنفيذ تقني وتدقيق خصوصية وأمن ووصول واختبارات شبكة وعدم اتصال.
4. تحقق موارد المساعدة وتواريخ انتهائها ومالك تشغيلي.
5. تجربة طيار وتحليل فهم ومحاولة وأثر سلبي وانسحاب وتفاوت وصول.
6. تدقيق اكتمال نهائي محدث يميز التصميم والتنفيذ والمراجعة والنشر.
