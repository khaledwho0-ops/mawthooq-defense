# متزن 2.0 — وثيقة متطلبات المنتج

الحالة: **مسودة بحثية تنفيذية — غير معتمدة للنشر**  
الإصدار: `0.1.0`  
المسار المثبت أولًا: `TRACK-HUMAN-001 — إنسان متزن`

## 1. المشكلة

المحتوى العربي الشائع للتطوير النفسي والمهارات الإنسانية غالبًا متفرق أو عام أو غير موثق أو منقول حرفيًا أو ممزوج بتشخيصات شعبية ووعود مبالغ فيها. وفي المقابل، المعرفة العلمية والمهنية موزعة بين أدلة ومراجعات ودراسات لا تتحول تلقائيًا إلى تعلم يومي مفهوم وقابل للتطبيق في قيود الحياة المصرية.

متزن يحل فجوة تعليمية، لا فجوة علاجية: يحول الأدلة والحدود وعدم اليقين إلى مناهج عربية منظمة، لكل دور منها مئة يوم كاملة، مع ممارسة خارج التطبيق وحق المستخدم في الحد الأدنى والتوقف وطلب مساعدة بشرية.

## 2. الرؤية والنتيجة المقصودة

منصة عربية أولًا لبناء قدرة إنسانية عبر أدوار الحياة. يخرج المتعلم من المسار قادرًا على:

- شرح المفاهيم بدقة أكبر ومنع إساءة استعمال المصطلحات النفسية.
- ملاحظة أفكار وانفعالات وسلوك وسياق دون تشخيص أو لوم شامل.
- اختيار ممارسة صغيرة آمنة وتعديلها وفق الطاقة والمال والخصوصية والقدرة.
- التواصل والاستماع والرفض والإصلاح مع إعطاء السلامة أولوية.
- التمييز بين التعليم الذاتي ومتى يلزم دعم أو تقييم أو تدخل عاجل بشري.
- الاحتفاظ بدليل شخصي مرن لا يعتمد على إدمان التطبيق أو الكمال.

لا تُعد النتيجة وعدًا بعلاج اضطراب أو تحسين سريري. إثبات الأثر يحتاج دراسة مستقلة مناسبة، وليس عدّ الإكمال.

## 3. المستخدمون والاحتياجات

### المستخدم الأساسي

بالغ يقرأ العربية ويريد تعلم مهارات إنسانية عامة في سياق دراسة أو عمل أو أسرة أو انتقال أو ضغط يومي. قد تكون طاقته أو قراءته أو دخله أو اتصاله أو خصوصيته محدودة. لا يفترض المنتج تشخيصًا ولا يطلبه للتسجيل.

### مستخدم منخفض الطاقة

يحتاج نسخة 3–5 دقائق، ولغة قصيرة، ومهمة واحدة، وعدم عقوبة عند التوقف. الحد الأدنى إكمال صالح، وليس نسخة ناقصة أخلاقيًا.

### مستخدم غير متأكد مما يحتاج

يحتاج أسئلة مجال غير تشخيصية، ثم مسارات تعليمية متعددة مع خيار «لست متأكدًا» وعتبة واضحة للمساعدة البشرية.

### مستخدم في وضع حساس أو خطر

لا يستمر معه تحسين الذات. تتقدم السلامة والتوجيه البشري، ولا يدخل النظام في تشخيص أو علاج أو تحقيق طويل. الموارد المحددة لا تظهر قبل تحقق حديث من مالكها.

### أصحاب المصلحة

باحث المحتوى، محرر العربية، مراجع الأدلة، المراجع السريري/الصحة العامة، الباحث المصري الاجتماعي/اللغوي، خبير الإتاحة، مسؤول الخصوصية، ودعم/فرز بلاغات الضرر. لا يستطيع دور واحد اعتماد كل المجالات.

## 4. الوظائف التي يريد المستخدم إنجازها

1. «أريد أن أفهم ما يحدث دون أن أحول نفسي أو الآخرين إلى تشخيص.»
2. «أريد خطوة محددة تناسب وقتي وطاقة يومي، لا نصيحة عامة.»
3. «أريد أن أعرف حدود الدليل وما الذي قد لا ينطبق عليّ.»
4. «أريد مسارًا يتقدم منطقيًا ويتذكر ما تعلمته، لا موجزًا عشوائيًا.»
5. «أريد أمثلة عربية ومصرية واقعية لا تفترض المال أو الخصوصية أو أسرة آمنة.»
6. «أريد أن أعود بعد الانقطاع دون مسح تقدمي أو خجل.»
7. «أريد أن أعرف متى لا تكفي الممارسة ومتى أحتاج إنسانًا أو خدمة.»
8. «أريد التحكم في يومياتي وبياناتي ومعالجة الذكاء الاصطناعي.»

## 5. نطاق الإصدار المحتوى الأول

- إكمال بحث ومعمار و100 يوم كاملة لمسار «إنسان متزن» وفق Parts A–S.
- أول عشرين يومًا طيار كامل، ثم أربع مراجعات نقدية مستقلة، ثم تعديل، ثم الأيام 21–100.
- مكتبات مشتركة قابلة لإعادة الاستخدام دون نسخ المنهج: المصادر، الادعاءات، المفاهيم، المهارات، الأنماط، التمارين، التجارب، المهمات، النصوص، العربية، والسلامة.
- مواصفات تنفيذ كاملة للبيانات والمنطق و50 شاشة؛ لا يلزم تغيير التطبيق الحالي قبل إثبات المحتوى.
- بنية تدعم كل المسارات المخططة ومئة يوم لكل مسار نهائي.

## 6. خارج النطاق الحالي

- علاج أو تشخيص أو وصف دواء أو تفسير أعراض فردية.
- إطلاق مورد أزمة مصري لم يؤكده مالكه حديثًا.
- ادعاء فاعلية سريرية أو «درجة اتزان».
- كتابة آلاف الأيام لمسارات لاحقة قبل اكتمال وتقييم المسار الأول.
- مجتمع مفتوح أو مجموعات علاج أو شبكة اجتماعية أو لوحة ترتيب.
- توصيات استثمار أو حميات أو مكملات أو مواجهة عنف.
- نقل يوم من مسار إلى آخر بتبديل اسم الدور.

## 7. مبادئ المحتوى غير القابلة للتفاوض

- الفهم قبل التغيير، والتعريف قبل النصيحة، والسبب قبل الكيفية.
- الفعل الواقعي خارج التطبيق أهم من وقت الشاشة.
- كل يوم كامل له 44 حقلًا، وثلاث جرعات، واستجابة فشل، وحد دليل، ومصادر.
- الممارسة اختيارية وقابلة للعكس ولها إشارات توقف وبدائل.
- كل عودة لمفهوم تضيف استرجاعًا أو سياقًا أو تعقيدًا؛ لا تكرار متنكر.
- الفصحى هي النص الأساسي، والمصرية تبسيط اختياري مضبوط بالمصطلحات.
- لا شراء مطلوب، ولا افتراض إنترنت سريع أو غرفة خاصة أو وسيلة انتقال أو علاج مدفوع.
- لا تنتقل حالة المحتوى إلى مراجعة مهنية بقرار AI أو اختبار بنيوي.

## 8. الرحلة الأساسية

```text
شرح الحدود والخصوصية
→ اختيار المسار والوقت والطاقة واللغة والخصوصية
→ رؤية خريطة 100 يوم دون إغراق
→ فتح اليوم الحالي
→ اختيار كامل/معياري/حد أدنى
→ فهم + فحص ذاتي اختياري + ممارسة
→ مهمة واقعية أو تخطٍ مبرر
→ انعكاس اختياري وخصوصي
→ تحقق فهم قصير
→ اليوم التالي أو عودة غير عقابية
```

المستخدم يستطيع في كل نقطة: التخفيض، التأجيل، التوقف، حذف كتابة، الإبلاغ، أو فتح حدود المساعدة.

## 9. منطق المنهج

- ترتيب معتمد على المتطلبات السابقة لا على التصفح العشوائي.
- فتح اليوم التالي لا يشترط إكمال كل نشاط اختياري.
- التخصيص يغير المثال والجرعة والتوقيت والبديل، ولا يحذف اليوم من بنية المئة.
- الاسترجاع يظهر دوريًا قبل عرض الإجابة، ثم حالة جديدة، ثم مراجعة خطأ وتعديل.
- الائتمان عبر المسارات يعرض درسًا كاملًا أو مراجعة سريعة أو تحديًا خاصًا بالدور، مع بقاء اليوم موجودًا.
- يوم الخطر أو العنف أو الأعراض الشديدة يتفوق على المنهج العادي.

## 10. الأيام الفائتة

- يوم واحد: استئناف مباشر.
- ثلاثة أيام: ملخص اختياري قصير.
- 7–10 أيام: ملخص + وضع مخفض + فحص عائق غير تشخيصي.
- 30 يومًا: الاستمرار من الموضع أو تقييم مصغر أو تذكير مكثف؛ لا إعادة إجبارية لليوم الأول.
- لا خسارة أو لون عقابي أو عد تنازلي أو قلب مكسور.

## 11. القياس

### مؤشرات تعلم

- شرح المفهوم بكلمات المستخدم.
- تذكر مؤجل دون فتح الدرس.
- تطبيق على مثال جديد.
- تجربة سلوك مرة واحدة وتسجيل الممكن/المفيد، لا «النجاح» فقط.
- ثقة مهارية ذاتية موسومة بوضوح كإبلاغ ذاتي.

### مؤشرات منتج

- اختيار الوضع حسب الطاقة.
- العودة بعد الانقطاع.
- نسبة المهام الواقعية إلى التفاعل داخل التطبيق.
- اكتمال تدفق الحذف والتصدير والموافقة.
- نجاح لوحة المفاتيح وقارئ الشاشة والتكبير والاتصال الضعيف.

### مؤشرات ضرر وحواجز

- زيادة الخجل أو الفحص أو الضيق أو الخلاف.
- غموض أو وصم أو افتراض مال/خصوصية/قدرة.
- بلاغ طبي أو سلامة أو قدم مصدر أو ترجمة سيئة.
- ترك المحتوى بسبب الحمل أو عدم الملاءمة، لا مجرد «dropout» سلبي.
- فشل وصول أو مورد مساعدة غير متاح.

لا يخلط أي مؤشر تفاعل بنتيجة سريرية.

## 12. السلامة وطلب المساعدة

المستويات: تعليم ذاتي، شخص موثوق، دعم مهني قد يفيد، تقييم سريري، عاجل/طوارئ. الشدة والاستمرار والتعطل والخطر هي إشارات تعليمية عامة، لا أداة تشخيص. عند الخطر تتوقف المهمة والسلسلة والنقاط والمساعد. لا تظهر خدمة بعينها حتى تسجل الجهة المالكة والنطاق والساعات والكلفة والخصوصية واختبار الوصول وتاريخ الانتهاء.

## 13. الخصوصية

- أقل بيانات ممكنة؛ لا يلزم دفتر لاستخدام المنهج.
- يوميات محلية افتراضيًا حيث يسمح التنفيذ، وخيار عدم التخزين.
- موافقة منفصلة ومفهومة قبل أي قراءة AI، قابلة للسحب دون خسارة المنهج.
- تصدير وحذف قابلان للتحقق، وفصل بيانات الاتصال عن المحتوى الحساس.
- تشفير النقل والتخزين السحابي حيث يوجد، وسياسة مدة واضحة.
- لا إعلان موجه أو بيع أو تدريب غير مصرح على بيانات عاطفية أو يوميات.

## 14. العربية والإتاحة

المحتوى RTL وفصحى واضحة مع شرح مصري اختياري. لا يعتمد المعنى على اللون أو الحركة أو الصوت. لوحة المفاتيح وقارئ الشاشة والتكبير 200–400% والتباين وتقليل الحركة والنص الكبير والتفريغ النصي متطلبات قبول. وضع القراءة المنخفضة يقلل الجمل والاختيارات ولا يحذف السلامة أو عدم اليقين.

## 15. الاتصال الضعيف وعدم الاتصال

النص أولًا، لا تشغيل تلقائي، صور اختيارية، أصول مضغوطة، وحفظ اليوم الحالي والقادم والتمارين. اليوميات المحلية لا تتطلب مزامنة. معلومات المساعدة المخزنة تعرض تاريخ التحقق وتحذير القدم وتختفي عند الانتهاء بدل تقديمها بثقة زائفة.

## 16. البحث والتوصيات

البحث يطابق لغة المستخدم وأخطاء شائعة ومرادفات إلى مفاهيم وأنماط محتملة بصيغة «قد يكون من المفيد استكشاف»، لا تشخيص. الكتب والدورات والتطبيقات تُقيّم بالدليل وصاحبها وادعاءاتها واللغة والكلفة والخصوصية والتوفر؛ الشهرة ليست معيارًا.

## 17. حالات المحتوى

`DRAFT → RESEARCHED → SOURCE_VERIFIED → SAFETY_REVIEWED → CULTURAL_REVIEWED → PROFESSIONAL_REVIEW_REQUIRED → PROFESSIONALLY_REVIEWED → PUBLISHED → STALE`

الانتقال ليس خطيًا تلقائيًا: التصحيح أو مصدر جديد أو بلاغ ضرر قد يعيد المادة إلى مسودة أو يوقفها. كل انتقال يسجل الشخص والنطاق والنسخة والوقت والقرار. `PROFESSIONALLY_REVIEWED` يتطلب إنسانًا مؤهلًا؛ `PUBLISHED` يتطلب كذلك اكتمال جميع بوابات الإصدار ذات الصلة.

## 18. معايير نجاح المسار الأول

- 100 ملف يوم، كل منها 44 حقلًا حقيقيًا مع مراجع صالحة.
- لا يوم عام أو مكرر أو بلا فعل أو حد أدنى أو استجابة فشل.
- تغطية القدرات الـ44 والأنماط الأساسية مع مراجعة متباعدة وتبعيات صحيحة.
- معالجة كل اعتراض في مراجعات الطيار والمئة يوم.
- اختبار مستخدم مصري للغة والواقعية والضرر والإتاحة.
- مراجعة بشرية من المجالات الأربعة وتحقق موارد المساعدة.
- اجتياز اختبارات المحتوى والبيانات والخصوصية والإتاحة والسلامة دون استخدام الاختبارات بديلًا للتوقيع البشري.

## 19. مخاطر المنتج وضوابطها

| الخطر | الضابط |
|---|---|
| تشخيص ذاتي أو للآخرين | تعريف/ما ليس هو/صياغة احتمالية/عتبة مساعدة/فحص كلمات محظورة |
| ممارسة تزيد الضيق | اختيارية، ثلاث جرعات، إشارات توقف، بديل خارجي، إبلاغ ضرر |
| لوم الفقر أو الرعاية | خريطة سيطرة وقيود وبدائل مجانية ومراجعة مصرية |
| مواجهة غير آمنة | فحص سلطة وخصوصية وانتقام وعنف قبل أي نص تواصل |
| إدمان وإحساس فشل | لا سلسلة عقابية، حد أدنى صالح، عودة دون مسح تقدم |
| تسرب اليوميات | محلي/لا تخزين، موافقة AI منفصلة، حذف وتصدير وتشفير |
| قدم موارد المساعدة | تحقق مالك، اختبار وصول، انتهاء تلقائي، بديل عام راجعه مختص |
| دليل ضعيف يتحول لقاعدة | سجل ادعاء وحدود وقوة ومخالفة وتطبيق مصري ومراجعة بشرية |
| نسخ المسارات | بحث دور مستقل وتدقيق دلالي عابر للمسارات قبل كل إصدار |

## 20. بوابات الإصدار

1. اكتمال البحث المكتبي الكافي للمسودة مع الفجوات معلنة.
2. مخطط 100 يوم وتدقيق Part O.
3. عشرون يومًا كاملة واختبارها.
4. أربع مراجعات مستقلة فعلية للنص وإغلاق الاعتراضات الداخلية.
5. الأيام 21–100 واختبارات المسار.
6. بحث مستخدم ومراجعات بشرية مصرية وإتاحة وخصوصية.
7. تحقق موارد المساعدة.
8. مواصفة المنتج والبيانات والشاشات والاختبارات.
9. تكامل آمن مع التطبيق القائم ثم تحقق طرفي.

حتى اكتمال 1–5 يسمى المسار مسودة محتوى. وحتى اكتمال 6–9 لا يسمى منشورًا أو معتمدًا.
